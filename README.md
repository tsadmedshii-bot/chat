# Чат — Пост ба 2 өрөөтэй чат

Монгол хэл дээрх орчин үеийн чат: Meta маягийн посттой нүүр хуудас, 2 чат
өрөө (🌍 нийтийн + 🏰 зөвшөөрөлтэй), зөвхөн нэг том админ, жижиг админ
(⚔️🛡️) эрх, 3D эможи сонгогч.

Энэ бол **standalone** төсөл (Node + Express + React + PostgreSQL) — Muse
artifact биш. GitHub-д оруулж, Node + Postgres ажиллуулдаг хостинг дээр
байршуулна.

> **Анхааруулга:** GitHub Pages дангаараа энэ аппыг ажиллуулж чадахгүй —
> Pages зөвхөн статик хуудас үйлчилдэг. Нэвтрэх, пост, чат хадгалах нь
> сервер + өгөгдлийн сан шаарддаг тул Render / Railway / VPS гэх мэт
> Node + Postgres хост хэрэгтэй.

## Онцлог

- **Нэвтрэлт:** бүртгэл (нэр / нэвтрэх нэр / нууц үг), нэвтрэх. **Анх
  бүртгүүлсэн хэрэглэгч цорын ганц 👑 том админ болно**, дараагийн бүх
  бүртгэл гишүүн (хэрэглэгч). Өөрөө админ болох зам байхгүй.
- **Нүүр (пост):** Meta маягаар пост оруулах, ❤️ таалагдлаа дарах
  (дахин дарвал буцаана), сэтгэгдэл бичих. Постыг зохиогч, том админ
  эсвэл жижиг админ устгаж болно.
- **2 өрөө:**
  - 🌍 **Нийтийн өрөө** — нэвтэрсэн хүн бүрд нээлттэй.
  - 🏰 **Зөвшөөрөлтэй өрөө** — зөвхөн том админаас зөвшөөрөл авсан хүн
    орж, уншиж, бичиж чадна. Гишүүн «Зөвшөөрөл хүсэх» товчоор хүсэлт
    илгээж, том админ «Гишүүд» хэсгээс зөвшөөрч / татгалзана.
    Зөвшөөрөлгүй гишүүн өрөөний мессежийг харж ч, бичиж ч чадахгүй.
- **Жижиг админ:** том админ итгэсэн гишүүндээ «⚔️🛡️ Жижиг админ
  болгох» товчоор эрх олгоно. Жижиг админы нэрний **дээр** ⚔️🛡️
  ЖИЖИГ АДМИН тэмдэг пост, чат, гишүүдийн жагсаалт — бүх газарт
  харагдана. Жижиг админ бусдын пост, мессежийг устгах эрхтэй;
  зөвшөөрөлтэй өрөөнд автоматаар орно. Том админ эрхийг нь хурааж болно.
- **Бан:** бандуулсан хэрэглэгч нэвтэрч чадахгүй, хуучин сессээрээ ч
  пост оруулж / чат бичиж чадахгүй болно. Бандуулсан нь «Гишүүд»
  жагсаалтад 🚫 Бандуулсан гэж харагдаж, тэндээс бандах/тайлах боломжтой.
  - Том админ хэнийг ч (жижиг админ, гишүүн) бандаж/тайлж чадна.
  - Жижиг админ **анхдагчаар бандаж болохгүй**. Том админ «🚫 Бандах эрх
    олгох» товчоор эрх олгож, хүссэн үедээ хурааж авч болно. Эрх авсан
    жижиг админ **зөвхөн энгийн хэрэглэгчийг** бандаж чадна — том админ
    болон өөр жижиг админыг бандаж болохгүй. Жижиг админ эрхээ хураалгавал
    бандах эрх нь ч хамт арилна.
- **3D эможи:** пост болон чатад 5 бүлэгтэй сонгогч — сэтгэл хөдлөл,
  амьтан, хоол, спорт ба зугаа, тэмдэгт (⚔️🛡️👑♛💎🔥🌟 г.м.). Эможи
  том, 3D сүүдэртэй.
- **Загвар:** гүн хөх неон, утасанд ээлтэй (390px шалгагдсан CSS).

Апп **хоосон** эхэлнэ — демо хэрэглэгч, демо пост, демо мессеж байхгүй.
Хостоор байршуулсны дараа хамгийн түрүүнд бүртгүүлсэн хүн том админ болно.

## Технологи

- Сервер: Node 20+ / TypeScript / Express 4 / Drizzle ORM / PostgreSQL 16
- Клиент: React 18 / Vite 5 / TypeScript (production-д Express статик үйлчилнэ)
- Нэвтрэлт: bcryptjs + opaque session token (DB-д хадгална)
- Төлбөрийн функц **байхгүй** — энэ чат үнэ төлбөргүй, QPay ч байхгүй.

## Орон нутагт ажиллуулах

Шаардлага: Node.js 20+, PostgreSQL 16 ажиллаж байх.

```bash
git clone <repo-url> chat
cd chat
npm install

cp .env.example .env
# .env дотор DATABASE_URL болон SESSION_SECRET-ээ оруулна

npm run db:migrate   # drizzle/*.sql шилжилтүүдийг хэрэглэнэ

npm run dev          # сервер :3001 + Vite клиент :5173 (proxy /api)
# эсвэл production маягаар:
npm run build
npm start            # http://localhost:3001
```

`.env` файлыг GitHub-д хэзээ ч оруулахгүй (`.gitignore`-д байгаа). Сервер
`.env` файл ачаалдаггүй (dotenv байхгүй) — `set -a; source .env; set +a`
гэж ачаалж ажиллуулна, эсвэл хувьсагчуудаа export хийнэ.

## Байршуулах (deploy)

### Render (санал болгож буй хялбар зам)

1. Render дээр PostgreSQL үүсгэнэ (Free tier болно).
2. Web Service үүсгэж энэ репогоо холбоно:
   - Build Command: `npm ci && npm run build`
   - Start Command: `npm run db:migrate && npm start`
   - Environment: `DATABASE_URL` (Postgres-ийн Internal Database URL),
     `SESSION_SECRET` (урт санамсаргүй утга).
3. Deploy дуусахаар өгсөн холбоосоор орж, бүртгүүлнэ.

### Railway

1. Railway төсөлд PostgreSQL нэмнэ.
2. Энэ репогоо Deploy хийнэ; `DATABASE_URL` автоматаар орж ирнэ.
3. `SESSION_SECRET` хувьсагч нэмж, Start Command нь дээрхтэй ижил.

### VPS / өөрийн сервер

```bash
# Node 20+ болон PostgreSQL суулгасан байна гэж үзнэ
git clone <repo-url> && cd chat
npm ci && npm run build
# .env үүсгэж DATABASE_URL / SESSION_SECRET оруулна
npm run db:migrate
npm start
# Production-д pm2 / systemd ашиглахыг зөвлөнө
```

### Docker

```bash
docker build -t chat .
docker run -p 3001:3001 \
  -e DATABASE_URL=<redacted> \
  -e SESSION_SECRET=<redacted> \
  chat
# Шилжилт: docker run ... node dist/server/src/migrate.js
```

`.github/workflows/ci.yml` нь push бүрт `typecheck` + `build` шалгана.

## Туршилтын дараалал (чухал!)

Хостоор байршуулсан шинэ сан **хоосон** эхэлдэг. Эхлээд эзэн
(та) бүртгүүлж 👑 том админ болоод, дараа нь линкээ бусдад түгээнэ.
Хэрвээ өөр хүн түрүүлж бүртгүүлбэл тэр хүн том админ болно.

1. Эзэн бүртгүүлнэ → 👑 ТОМ АДМИН тэмдэг харагдана.
2. Бусад нь хэрэглэгчээр бүртгүүлнэ.
3. Хэрэглэгч 🏰 өрөөнд «Зөвшөөрөл хүсэх» дарна.
4. Эзэн «Гишүүд» хэсгээс «Зөвшөөрөх» дарна → хэрэглэгч өрөөнд орно.
5. Эзэн итгэсэн хүндээ «Жижиг админ болгох» дарна → ⚔️🛡️ тэмдэг
   нэрний дээр нь гарна.

## Төслийн бүтэц

```
chat/
  client/            React + Vite клиент (Mongolian UI)
    src/api.ts       API клиент
    src/pages/       Нүүр (пост) / Нэвтрэх / Өрөөнүүд / Гишүүд
    src/components/  3D эможи сонгогч + нэрний дээрх эрхний тэмдэг
  server/
    src/index.ts     Express апп (API + статик клиент)
    src/routes.ts    Бүх API endpoint
    src/auth.ts      Бүртгэл/нэвтрэлт/сесс
    src/schema.ts    Drizzle схем
    src/migrate.ts   SQL шилжилт ажиллуулагч
  shared/src/types.ts  Клиент/серверийн нийтлэг төрөл + API гэрээ
  drizzle/           SQL шилжилтүүд (0001_init)
```

API endpoint-үүдийг `server/src/routes.ts`-ээс, төрлүүдийг
`shared/src/types.ts`-ээс харна уу.

## Утасны APK

Энэ апп сервер + өгөгдлийн сан шаарддаг тул **офлайн APK болохгүй**.
Боломжтой зам: аппыг дээрх заавраар байршуулж нийтийн холбоостой болгоод,
тэр холбоосыг WebView-гоор боосон APK хийх (Capacitor эсвэл Android
WebView wrapper). APK интернет шаардана.
